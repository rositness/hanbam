# Формат контента

Весь учебный материал лежит в `content/`. Чтобы файлы оставались компактными, слова и примеры записываются массивами,
а приложение само превращает их в объекты.

## content/course.json — линии и порядок юнитов

```json
{
  "romanizationAutoUntil": "u04",
  "lines": [
    { "id": "L1", "num": "1", "title": "Линия 1 · A1", "ko": "1호선", "subtitle": "…", "color": "#4fd8ff",
      "units": ["u01", "u02"] },
    { "id": "L2", "num": "2", "title": "Линия 2 · A2", "requires": "L1", "color": "#ff7ab6", "units": ["u09"] }
  ]
}
```

* `requires` — линия откроется, когда пройдена указанная линия.
* `romanizationAutoUntil` — до какого юнита включительно латиница видна всегда (в режиме «Постепенно»).

## Юнит со словами: content/units/uXX.json

Необязательные поля оформления: `"color": "#ff922b"` — цвет юнита на карте (иначе берётся из палитры по порядку) и `"scene": "ramen"` — иллюстрация рядом с тропинкой. Доступные сцены: hangul, gate, balloons, house, ramen, clock, tower, shop, subway, sunrise, guitar, weather, books, health, hearts, calendar, plane, apartment, lanterns, phone, bank (см. js/core/scenes.js).

```json
{
  "id": "u05",
  "title": "Время и даты", "ko": "시간", "icon": "⏰",
  "description": "Короткое описание юнита",
  "lessons": [
    {
      "id": "u05-1",
      "title": "Который час?",
      "goal": "Назвать и спросить время",
      "words": [
        ["시간", "sigan", "время; час"],
        ["일", "il", "число месяца", "일#date"]
      ],
      "grammar": {
        "title": "Который час: 시 и 분",
        "body": ["Абзац с **жирным** и `корейским` текстом", "Ещё абзац"],
        "examples": [["지금 몇 시예요?", "jigeum myeot siyeyo?", "Который час?"]],
        "note": "Необязательная заметка"
      },
      "sentences": [
        ["세 시 반이에요.", "se si banieyo.", "Половина четвёртого."]
      ],
      "drills": [
        { "q": "지금 ___ 시예요?", "a": "몇", "opts": ["뭐", "얼마"], "ru": "Который час?", "hint": "Необязательная подсказка" }
      ],
      "dialog": {
        "title": "Успеем в кино?", "scene": "Короткое описание сцены",
        "lines": [["유나", "지금 몇 시예요?", "jigeum myeot siyeyo?", "Сколько времени?"]]
      }
    }
  ],
  "phrases": [["내일 봐요.", "naeil bwayo.", "До завтра."]]
}
```

| Поле | Что это | Что из этого получается |
|---|---|---|
| `words` | `[корейский, романизация, перевод, id?]` | Слова урока: выбор перевода, аудирование, сопоставление, ввод. После урока попадают в SRS |
| 4-й элемент слова | id для омонимов (`"개#count"`) | Нужен, если такое же написание уже есть с другим значением |
| `sentences` | `[корейский, романизация, перевод]` | Сборка предложения, сборка на слух, «Скажи вслух». Лучше 5–6 штук по 3–6 слов |
| `drills` | пропуск `___` в `q`, ответ `a`, неправильные варианты `opts` | Упражнения на грамматику. Неверные варианты должны быть действительно неверными |
| `grammar` | объяснение с примерами | Показывается перед уроком и в разделе «Грамматика» |
| `dialog.lines` | `[кто, корейский, романизация, перевод]` | Диалог в конце урока и в «Библиотеке» |
| `phrases` | разговорник юнита | Раздел «Фразы» и страница юнита |

## Юнит хангыля: `"kind": "hangul"`

```json
{
  "id": "h2", "kind": "hangul", "title": "Базовые согласные", "ko": "자음", "icon": "ㄱ",
  "lessons": [
    {
      "id": "h2-1", "title": "ㄱ ㄴ ㄷ ㄹ",
      "letters": ["ㄱ", "ㄴ", "ㄷ", "ㄹ"],
      "theory": ["Абзац теории"],
      "rules": ["liaison"],
      "pairs": [["가", "카", "까"]],
      "read": [
        ["고기", "gogi", "мясо"],
        ["한국어", "hangugeo", "корейский язык", "한구거", ["한궁어"]]
      ]
    }
  ]
}
```

* `letters` — буквы из `content/hangul.json`: звук, подсказка, пример, порядок черт.
* `read` — слова для чтения. 4-й элемент — произношение (для упражнения «Как это произносится?»), 5-й — неверные варианты произношения.
* `pairs` — группы похожих слогов для аудирования (обычный / придыхательный / напряжённый).
* `rules` — id правил чтения из `hangul.json`.

## Истории: content/stories.json

```json
{
  "id": "s09", "title": "Название", "ko": "제목", "emoji": "📖", "level": "A2", "after": "u12",
  "lines": [
    ["", "Слова рассказчика.", "romanizatsiya", "Перевод"],
    ["민수", "Реплика персонажа.", "romanizatsiya", "Перевод"]
  ],
  "questions": [{ "after": 2, "q": "Вопрос по-русски?", "opts": ["Верный ответ", "Неверный", "Неверный"], "a": 0 }]
}
```

* Пустое «кто» — рассказчик (озвучивается отдельным голосом). Пол персонажей укажите в `content/voices.json`.
* `after` — юнит, после прохождения которого история откроется. `questions[].after` — номер строки (с 1), после которой задаётся вопрос; варианты в приложении перемешиваются.
* После добавления запустите `node tools/tts/generate.mjs`, чтобы озвучить новые реплики.

## Правила хорошего контента

* Романизация — **по произношению** (RR): `한국어 → hangugeo`, `감사합니다 → gamsahamnida`.
* Только вежливый стиль `-요` в примерах, пока не введён официальный `-ㅂ니다`.
* Новые слова урока по возможности используйте в его предложениях и диалоге.
* После правок запускайте `node tools/validate-content.js`.
