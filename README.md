# 한밤 · Ханбам — корейский с нуля

Приложение для изучения корейского языка от алфавита до разговорного уровня (≈ TOPIK 1–2 / A2).
Интерфейс на русском. Работает в браузере, ставится на телефон как приложение (PWA), работает офлайн.
Бэкенда и аккаунтов нет: прогресс хранится на устройстве, его можно выгрузить в файл и загрузить на другом телефоне.

**Ссылка на приложение:** https://rositness.github.io/hanbam/ — отправьте её друзьям.
Исходники: https://github.com/rositness/hanbam

### Как обновить опубликованное приложение
После любых правок увеличьте `VERSION` в `sw.js` (например, `v1.0.1`) и выполните в папке проекта:

```powershell
git add -A
git commit -m "Обновление"
git push
```

Через 1–2 минуты GitHub Pages обновит сайт, а у пользователей появится кнопка «Обновить».

| **Грамматика** | 48 тем: частицы, вежливость, времена, отрицание, связки, -고 싶어요, -(으)면 и др. |
| **Диалоги** | 48 диалогов (292 реплики): «прочитай и послушай» с разными голосами персонажей и ролевая игра 🎭 + 128 фраз разговорника |

Каждый пример даётся в трёх видах: хангыль, романизация (по произношению, официальная система RR) и перевод.
Романизация убирается постепенно: в первых юнитах она видна всегда, дальше показывается по нажатию. Режим меняется в настройках.

## Запуск на компьютере

Нужен [Node.js](https://nodejs.org) (любой современной версии). Никаких `npm install`.

```powershell
node tools/serve.js
```

Откройте http://localhost:5173. Сервер также пишет адрес в локальной сети. Если открыть его на телефоне в той же Wi-Fi-сети, можно проверить приложение с телефона, но установка PWA и офлайн там не заработают: для них нужен HTTPS (см. «Публикация»).

> Двойной клик по `index.html` не сработает: браузер не даёт загружать JSON с диска. Нужен сервер.

При разработке на `localhost` service worker отключён, чтобы правки были видны сразу.
Чтобы проверить офлайн-режим локально, выполните в консоли браузера `localStorage.setItem('hb-sw','1')` и обновите страницу.

## Публикация (бесплатно), чтобы поделиться ссылкой

Это статический сайт, поэтому подойдёт любой бесплатный хостинг. Все варианты дают HTTPS, а значит работают установка на телефон и офлайн-режим.

### Вариант 1. Netlify Drop — самый простой (без аккаунта Git)
1. Откройте https://app.netlify.com/drop.
2. Перетащите туда **всю папку** `korean-app`.
3. Получите ссылку вида `https://имя.netlify.app` — её можно отправлять друзьям.
   Чтобы ссылка не пропала, зарегистрируйтесь (бесплатно) и переименуйте сайт в настройках.

### Вариант 2. GitHub Pages
1. Создайте репозиторий на GitHub и загрузите в него содержимое папки (кнопка **Add file → Upload files** или через git):
   ```powershell
   git init
   git add .
   git commit -m "Ханбам"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/hanbam.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/hanbam/`.

### Вариант 3. Cloudflare Pages
1. https://dash.cloudflare.com → **Workers & Pages → Create → Pages → Upload assets**.
2. Загрузите папку, назовите проект — получите `https://имя.pages.dev`.

Все пути в приложении относительные, поэтому оно работает и в подпапке (как на GitHub Pages).

## Озвучка и распознавание речи

Все слова, фразы и диалоги **заранее озвучены нейроголосами Microsoft** (женский SunHi, мужские InJoon и Hyunsu) — звучат как носитель языка.
В диалогах у каждого персонажа свой голос по полу. Записи лежат в `audio/` (≈ 2400 файлов, 31 МБ), скачиваются по мере прослушивания
и сохраняются для офлайна; в **Настройках** можно скачать всю озвучку сразу.

Если записи для какого-то текста нет (например, в новом уроке), используется синтез речи устройства (Web Speech API, `ko-KR`).

**Озвучить новые уроки** (нужен интернет, бесплатно, без ключей):
```powershell
cd tools/tts
npm install
cd ../..
node tools/tts/generate.mjs
```
Скрипт озвучит только то, чего ещё нет, и обновит `audio/index.json`. Пол новых персонажей диалогов укажите в `content/voices.json`.

Голос устройства (запасной вариант):

* **iPhone / Mac:** корейский голос (Yuna) обычно уже есть.
* **Android:** Настройки → Система → Язык → Синтез речи → Google → установить «Корейский».
* **Windows:** Параметры → Время и язык → Речь → Добавить голоса → Корейский.

Упражнение «Скажи вслух» использует распознавание речи там, где браузер его поддерживает (Chrome на Android и компьютере, частично Safari). В остальных браузерах включается режим самопроверки: послушайте образец, повторите вслух и нажмите «Готово». Упражнения на речь можно выключить в настройках.

## Прогресс

Всё хранится в IndexedDB браузера (если она недоступна, используется localStorage).
**Профиль → Экспорт** сохраняет файл `hanbam-progress-ДАТА.json`, **Импорт** загружает его на другом устройстве.
Очистка данных сайта в браузере удалит прогресс, поэтому иногда делайте экспорт.

## Как добавить уроки

Весь контент лежит в JSON-файлах в папке `content/`, код трогать не нужно.
Подробный формат описан в [docs/CONTENT.md](docs/CONTENT.md). Если коротко:

1. Откройте файл юнита, например `content/units/u05.json`, и добавьте объект в массив `lessons`
   (или создайте новый файл юнита `u17.json` и впишите его id в нужную линию в `content/course.json`).
2. Упражнения (выбор, аудирование, сборка, ввод, речь, тест юнита) **генерируются автоматически** из слов, предложений и пропусков.
3. Проверьте контент:
   ```powershell
   node tools/validate-content.js
   ```
   Скрипт найдёт ошибки структуры, случайные иероглифы, кириллицу и греческие буквы в романизации, дубли слов и посчитает объём курса.
   Латиницу можно сверить с правилами произношения (связывание, назализация, ассимиляция и т.д.):
   ```powershell
   node tools/check-rom.js
   ```
4. После правок на опубликованном сайте увеличьте `VERSION` в `sw.js`. Тогда пользователи увидят предложение обновиться.

## Структура проекта

```
index.html, manifest.json, sw.js   оболочка, PWA, офлайн
css/app.css                        дизайн «Сеул ночью», тёмная и светлая темы
js/app.js                          запуск, маршруты, нижняя навигация
js/core/                           хранилище, контент, озвучка, распознавание, SRS, XP/серии/достижения, хангыль
js/exercises/                      генератор упражнений, их отрисовка, корейская клавиатура, прописи
js/screens/                        экраны: карта, урок, хангыль, библиотека, диалоги, повторение, профиль
content/                           course.json, hangul.json, units/*.json — весь учебный контент
tools/                             serve.js (сервер), validate-content.js, check-rom.js (аудит латиницы),
                                   tts/generate.mjs (озвучка), make-icons.ps1, autoplay.js (автотест)
audio/                             записи нейроголосов (audio/index.json — список)
```

Никаких зависимостей и сборки: чистые HTML, CSS и ES-модули.
